# KubuKids — téléchargements

Ce dépôt contient **uniquement les applications compilées** de KubuKids (aucun code source),
publiées dans ses **[Releases](https://github.com/Bobo5diallo224/kubukids-telechargements/releases)**.

de 3 à 10 ans, en Guinée et au Sénégal. Présentation et guide d'installation : site de KubuKids.
